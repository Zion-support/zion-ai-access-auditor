# Zion AI Access Auditor

**Identity and access review automation with least-privilege insights** — part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/).

🌐 **Live site:** https://ziontechgroup.com/zion-ai-access-auditor/

## What it does
- Automates periodic user access reviews (UARs) across IdP, cloud, and SaaS
- Flags privilege creep, dormant accounts, and toxic permission combinations
- Recommends least-privilege role adjustments with confidence scores
- Produces auditor-ready access certification evidence
